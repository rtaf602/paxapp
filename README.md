# 602 SEAT PLAN · ผังที่นั่งผู้โดยสาร ฝูงบิน 602

หน้ารวมผังที่นั่งผู้โดยสาร **สำหรับหน่วยงานภายนอก** อยู่ที่ `https://rtaf602.github.io/paxapp/`

ใครก็เปิดหน้านี้ได้ ไม่ต้องเข้าสู่ระบบ และไม่ต้องใส่รหัส หน้านี้มีแค่ลิงก์ไปผังที่นั่ง 4 ระบบ ผังที่นั่งแต่ละระบบยังถามภารกิจและรหัสผ่านของภารกิจเหมือนเดิม

| รหัสเว็บ | แบบเครื่อง | ลิงก์ |
|---|---|---|
| WEB6 | A340 | `/a340_seatplan_passenger/` |
| WEB7 | A320-05 | `/a320-05_seatplan_passenger/` |
| WEB8 | A320-03 | `/a320-03_seatplan_passenger/` |
| WEB9 | A319 | `/a319_seatplan_passenger/` |

ภายใน ฝูง.602 ใช้หน้า OPS 602 (repo `app`) ซึ่งต้องเข้าสู่ระบบกลาง หน้านี้ออกแบบให้ต่างจากหน้านั้นโดยตั้งใจ (โทนฟ้าขาว การ์ดแบบบัตรขึ้นเครื่อง) คนนอกจะได้ไม่สับสนว่าเป็นหน้าเดียวกัน

มีปุ่มแชร์ลิงก์ (แชร์ของมือถือ, LINE, คัดลอกลิงก์, QR) และวิธีติดตั้งเป็นแอปบน Android, iPhone และ Samsung

## ไฟล์

| ไฟล์ | คืออะไร |
|---|---|
| `index.html` | หน้าทั้งหมด: หัวหน้า เวลาไทยและเวลา Zulu การ์ดแบบเครื่อง |
| `hero-plane.jpg` | รูปเครื่องบินในแถบหัว |
| `manifest.webmanifest`, `icons/` | ชื่อแอป (602 SEAT PLAN) และไอคอนเมื่อกด "เพิ่มลงหน้าจอหลัก" |

## เพิ่มหรือแก้แบบเครื่อง

แก้ `TYPES` ใน `index.html` แต่ละแบบมี

- `code` รหัสเว็บ (ตรงกับหน้า OPS 602)
- `type` ชื่อแบบเครื่องที่แสดงบนการ์ด
- `slug` ชื่อ repo ของผังที่นั่งนั้น (ลิงก์จะเป็น `https://rtaf602.github.io/<slug>/`)
